# Menu Sadah — Locked Build Standard

This repo hosts **Menu Sadah** premium bilingual (AR+EN) menu builds, delivered live at `menu-sadah.com/<slug>`. Reference build: `menus/cofleur/` (Maison de Cofleur). Follow this standard for every new cafe — no exceptions unless the user says so.

## The locked standard (per build)
1. **SPY the brand first** — logo, Instagram, signage, press, and especially any existing menu platform. Many Saudi cafes use Yalla QR (`<slug>.yallaqrcodes.com`) with public JSON: `/api/info/`, `/api/categories/`, `/api/items-light/`. Pull exact names (their AR spelling!), prices, calories, descriptions, per-item artwork, links, VAT no.
2. **Signature hero animation under the logo** — the brand's own logo mark rebuilt as animated SVG (elegant + abstract, never childish). Parametric trace, entrance stagger + subtle infinite breathe, `prefers-reduced-motion` static fallback.
3. **Typography** — pull their exact fonts; if commercial, closest Google equivalents, **self-hosted woff2** (never CDN). English slightly bigger than its Arabic everywhere.
4. **Outreach** — gift-first (the live link IS the gift), never lead with price, **never say "QR menu"**, voice-matched from their own captions. Templates in `docs/<slug>/OUTREACH.md`.
5. **Offer (current):** SR 499 build + SR 199/mo · founding option SR 999 (SR 500 deposit). Mention only when asked.
6. **Bulletproof** — 5× design passes with screenshots at **375px in real Chromium**; OCD fidelity audit (DOM vs source JSON: every name/price/calorie 1:1); no horizontal overflow; fonts loaded; broken-image check.

## Turnkey deliverables (ALWAYS all of these — make their life and our life easy)
- `menus/<slug>/index.html` — self-contained static page (local fonts + local images, zero external deps), generated by `menus/<slug>/_build/build.mjs` from `data/menu.json`.
- **Live link** stated everywhere: `menu-sadah.com/<slug>`.
- **Table QR pack** in `menus/<slug>/qr/`: branded QR SVG + PNG (+ plain fallback PNG), `print.html` **and ready `table-cards.pdf`** (A4, 4 cards, cut guides, A6-holder size).
- **QR must be verified**: decode sweep across sizes (300–1200px), rotation, blur. Rounded-square modules + mildly-rounded finders scan; heavy-rounded finders and center logo knockouts DON'T — put the logo above the QR on the card, never inside.
- `docs/<slug>/HANDOFF.md` — owner how-to in plain Arabic (link placement, print instructions, how to request edits) + seller section (files, deploy, update flow).
- `docs/<slug>/OUTREACH.md` — DM scripts AR+EN, follow-up, price talk, objections.
- `docs/<slug>/BRAND-SPY.md` — palette hex, fonts, links, extraction endpoints.

## Environment notes
- Headless Chromium **cannot reach the internet through the session proxy** (CONNECT reset). Use `curl` for all remote fetches; use local Chromium (`python3 -m http.server` + Playwright at `/opt/node22/lib/node_modules/playwright/index.mjs`, browsers in `/opt/pw-browsers`) for rendering, screenshots, and print-to-PDF.
- Fonts: fetch Google Fonts css2 with a Chrome UA via curl, download woff2, subset per language, `@font-face` with `unicode-range`.
- Item images: use the platform's own square crops (their chosen framing); download all into `assets/items/`.

## Deploy
Copy `menus/<slug>/` (minus `_build/`, optional) to menu-sadah.com web root as `/<slug>/`. All paths relative. QR codes point at the live URL — generate them only after the slug is final.
